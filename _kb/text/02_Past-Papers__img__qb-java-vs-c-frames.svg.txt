Call mechanism is identical: caller prepares arguments, call pushes return address, callee builds the frame.
Java passes the reference BY VALUE: callee can change the object's fields, but cannot re-point the caller's variable.
C: passing a pointer gives the same effect; passing the struct itself gives the callee a private copy.
