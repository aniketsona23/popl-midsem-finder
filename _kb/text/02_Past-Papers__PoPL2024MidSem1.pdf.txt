Because Module2.c doesn’t have any instantiation of the type struct Abstract, it needs
only to know that Class is a pointer to that type. As long as all pointers are of the same
size and layout, it doesn’t require the type just to pass on a pointer. The type’s storage
information—size and layout—is needed only when a pointer is dereferenced or the type
value is to be passed around instead of the pointer.

A6.
In the current program, we will get a segfault in line 31 because the functions f,g
return 0, the two nested if blocks are not executed, hence object1’s Abstract function
pointer member is uninitialised, thus a call is placed to an invalid text section address. When

A7.
The max number of stackframes of f and g together are n + 1; both functions have
the same stackframe size; the total size is
(n + 1) ∗(sizeof(int) + 3 ∗sizeof(void∗))
because one integer paramter and three addresses (return address, stack pointer, stack frame
base pointer) are to be saved.
