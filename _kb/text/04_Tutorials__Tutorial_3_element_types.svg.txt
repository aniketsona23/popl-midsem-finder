Element types: one List&lt;T&gt;, many element types
«abstract»  Shape
+ area() const : double = 0
+ name() const : const char* = 0
+ virtual ~Shape()
Circle
- r : double
+ area() = πr²
Rect
- w, h : double
+ area() = w·h
List&lt;shared_ptr&lt;Shape&gt;&gt;
same class template, T = ShapePtr
pushBack(ShapePtr(new Circle(1)))
pushBack(ShapePtr(new Rect(2,5)))
sort([](a,b){ return a-&gt;area()
&lt; b-&gt;area(); })
holds 0..*
area() is chosen at run time (vtbl) for each element
List&lt;int&gt;, List&lt;std::string&gt;, List&lt;ShapePtr&gt; are all instances of the one template List&lt;T&gt; – the list type is unchanged.
