Tutorial 3 – Container class hierarchy
«abstract»  Container&lt;T&gt;
+ put(const T&amp;) = 0
+ get() : T = 0
+ peek() const : const T&amp; = 0
+ size() const : size_t = 0
+ empty() : bool
+ virtual ~Container()
is-a (public inheritance, overrides put/get/peek/size)
Stack&lt;T&gt;
LIFO
- items_ : List&lt;T&gt;
+ put  → pushFront
+ get  → popFront
+ peek → front
Queue&lt;T&gt;
FIFO
- items_ : List&lt;T&gt;
+ put  → pushBack
+ get  → popFront
+ peek → front
Deque&lt;T&gt;
both ends, no middle access
- items_ : List&lt;T&gt;
+ putFront / putBack
+ getFront / getBack
+ peekFront / peekBack
PriorityQueue&lt;T,Less&gt;
binary heap (max / min)
- heap_ : vector&lt;T&gt;
- siftUp / siftDown
+ put / get  O(log n)
